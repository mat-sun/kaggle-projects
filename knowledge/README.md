## How To Write

知見は、あとから別コンペで使える粒度で書く。

推奨フォーマット:

```text
## Topic

### 使う場面

### 手順

### 注意点

### 関連したコンペ・実験
```

「効いた手法」だけでなく、「効かなかった条件」や「リークにつながりやすい注意点」も残す。
